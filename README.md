# 🎬 Netflix Clone

A Netflix-inspired streaming website built using **HTML, CSS, and JavaScript**. This project recreates the look and feel of Netflix with a modern interface, movie and series browsing, search functionality, and login and registration pages.

## ✨ Features

- 🎥 Netflix-inspired homepage and user interface
- 🔍 Search functionality for movies and series
- 📝 Login and registration pages
- 🖼️ Background images and modern visual design
- 📱 Responsive layout for different screen sizes
- 🎞️ Movie and TV series sections
- ⚡ Interactive elements powered by JavaScript

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layouts, animations, and visual effects
- **JavaScript** — Search and interactive functionality
